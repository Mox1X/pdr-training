# ПДР Практика

Вебтренажер дорожніх знаків України. React, TypeScript, Vite.

## Запуск

Потрібен Node.js 22.12+ або 24+.

```sh
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай http://localhost:5173).
Для перегляду на телефоні в тій самій локальній мережі використайте Network-адресу Vite.

## Режими та прогрес

- 369 номерів знаків і табличок у семи групах, 389 оригінальних ілюстрацій.
- Навчання: до 10 різних знаків із вибраних категорій, по 4 варіанти. Проблемні знаки мають вагу 4 замість 1.
- Екзамен: 20 різних випадкових знаків з усіх груп; результат тільки наприкінці.
- Робота над помилками: до 10 знаків із помилками, які ще не вивчено.
- Статистика: вивчено, ще не перевірено, прогрес груп, помилки та повторювані плутанини.
- Фіксація першої відповіді, правильний варіант і коротке пояснення.
- Результат, розбір помилок і новий тест.
- Український інтерфейс, адаптація для телефона та керування клавіатурою.

Без таймера, акаунтів і сервера. Прогрес зберігається в localStorage (`pdr.progress.v2`) лише в цьому браузері.
Перший правильний вибір призначає повторення через 24 години. Наступні успіхи після настання строку — через 3, потім 7 днів.
Після успішної перевірки через 7 днів знак вважається вивченим; підтримувальний інтервал — тиждень.
Ранні правильні відповіді не змінюють етап або строк; помилка скидає етап і призначає повторення через день.
Окремий режим «Повторити сьогодні» вибирає до 10 належних повторень, починаючи з найстаріших строків.
Версія 2 починає прогрес заново, без міграції попередніх даних; старий ключ не читається й не видаляється.

Формати практики: знак → назва, назва → знак, спочатку згадати (варіанти приховані до натискання кнопки).
Усі формати мають спільний розклад; згадування оцінюється лише за подальшим вибором, без самооцінки.
Екзамен завжди використовує знак → назва. Час кожного вибору зберігається для правильного оновлення розкладу після завершення.

Варіанти генеруються під час створення запитання за візуальними сімействами, значенням та словами назви.
До двох місць отримують попередні особисті плутанини, з вагою за числом помилок.
Еквівалентні та неоднозначні члени сімейства виключаються. Порядок, зображення й варіанти фіксуються до кінця сесії.
Пояснення та офіційне джерело доступні після кожної відповіді; додаткові умови розгортаються окремо.
Після екзамену можна прочитати пояснення до всіх 20 відповідей.
Оновлення сторінки скидає поточний тест. Відповіді навчання й повторення зберігаються відразу,
екзамену — тільки після завершення. Незавершений екзамен не впливає на статистику.
Повторювані плутанини — один і той самий неправильний варіант, вибраний щонайменше двічі.
Скидання статистики потребує підтвердження на її екрані. Якщо сховище недоступне,
застосунок працює в пам’яті з попередженням; пошкоджені дані не перезаписуються автоматично.
Зображення та шрифти локальні; зовнішні запити потрібні лише для переходу до джерела.

## Перевірки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерні тести перевіряють повну сесію, пояснення, правильний результат, повторний тест,
оновлення сторінки, керування клавіатурою, відсутність зовнішніх запитів і поведінку при

## Дані та походження зображень

Номери, назви і значення звірено з [офіційними ПДР України](https://zakon.rada.gov.ua/laws/show/1306-2001-%D0%BF/print)
11.11.2026; на той момент сторінка містила редакцію від 14.10.2026.
Пояснення — стислий навчальний переказ; для повних умов та винятків кожен знак має посилання на відповідний пункт.
Це тренування розпізнавання знаків, без відтворення офіційних екзаменаційних білетів.

Оригінальні зображення без змін витягнуто з [Додатка 1 до ПДР](https://zakon.rada.gov.ua/laws/file/text/141/f89740n2524.docx).
Їхня вихідна роздільність — близько 100×100 px. `public/signs/sources.json` містить URL джерела,
назву зображення всередині документа та SHA-256 кожного файлу.

Для відтворення імпорту завантажте офіційний DOCX і виконайте:

```sh
python scripts/import-signs.py /path/to/f89740n2524.docx
```

Каталог: `src/data/catalogue.json`, типи та категорії: `src/data/signs.ts`.
Офіційні назви збережено в `name`, навчальні уточнення — в `answerLabel`.
Варіанти ілюстрацій одного номера мають спільну статистику; зображення фіксується на час запитання та розбору.
Однакові за значенням графічні варіанти не пропонуються як різні відповіді.

Контрольний перелік визначень із тексту ПДР — `data/catalogue/inventory.json`.
Явна відповідність усіх оригінальних зображень номерам — `data/catalogue/image-map.json`.
Звіт повноти — `data/catalogue/report.json`, редакція і контрольні суми — `data/catalogue/source.json`.
Групи: 58 попереджувальних, 6 пріоритету, 45 заборонних, 26 наказових,
132 інформаційно-вказівні, 29 сервісних і 73 таблички.

Повторна підготовка (з кореня проєкту):

```sh
python scripts/extract-inventory.py /path/to/official-print.html
python scripts/import-signs.py /path/to/f89740n2524.docx
python scripts/build-catalogue.py
```

Зміна вихідного DOCX зупиняє імпорт: спочатку потрібно перевірити нову редакцію та карту зображень.
У чинному документі вручну узгоджено опечатки: 1.3 → 1.35, 5.10..4 → 5.10.4,
5.81.3 → 5.81. Табличка 7.30 розміщена поза основними таблицями.
Пояснення нових знаків містять відповідний абзац офіційного тексту; повні винятки та пов’язані вимоги доступні за посиланням на пункт.
Логіка сесії без прив'язки до React: `src/quiz.ts`.
Під час додавання знака вкажіть офіційну назву, навчальне уточнення за потреби,
локальний шлях до зображення та посилання на офіційний пункт. Варіанти відповіді
генерує `src/options.ts`; для нового візуального сімейства перевірте його класифікацію та сумісність. Кількість запитань налаштовується
через `QUESTION_COUNT` у `src/quiz.ts`; каталог має містити щонайменше стільки знаків.

Шрифт Manrope розповсюджується за SIL Open Font License; ліцензія доступна у пакеті
`@fontsource-variable/manrope/LICENSE`. Під час деплою розміщуйте вміст `dist/` у корені домену.


## Відновлення зображень і структура

Екрани знаходяться у `src/screens/`, спільні елементи — у `src/components/`.
`useProgress` відповідає за сховище, `useQuizSession` — за сесію й передачу лише оцінених відповідей.
`App.tsx` містить оболонку та навігацію.

Якщо необхідне зображення не завантажилося, відповіді блокуються. Кнопка повторення
завантажує ті самі зображення; пропуск не впливає на оцінку або інтервали.
Заміна береться з невикористаних допустимих знаків. Якщо замін немає, сесія завершується
як скорочена, а екзамен — як неповний. За відсутності відповідей оцінка не обчислюється.

## Перевірка змісту

```sh
npm run check:content
```

Для цієї перевірки й повного набору тестів потрібен Python 3.
Збережений офіційний HTML редакції 14.10.2026 розташований у `data/catalogue/source/`;
стан редакції повторно звірено 11.11.2026 на офіційному порталі.
`supporting.json` прив’язує додаткові умови до окремих абзаців; загальні правила групи
показуються окремо від визначення знака.
`content-review.json` містить записи для 369 позицій: метод, примітки, джерело, автора
сверки та хеш перевіреного набору текстів. Сверка виконана Codex з допомогою ШІ;
вона не є незалежним висновком юриста.
Автоматична перевірка підтверджує номер, заголовок, абзац і незмінність змісту, але
не встановлює юридичний сенс. Вона не присвоює статус `reviewed`: зміна тексту,
уточнення, додаткових умов чи джерела вимагає нової змістовної сверки і оновлення запису.
